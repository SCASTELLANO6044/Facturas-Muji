# Facturas Muji

A quiet, single-purpose desktop utility for consecutively naming invoice files.

Based on the ui-ux-pro-max design-system search: flat surfaces, minimal decoration,
clear typography, one primary action, visible focus and brief state transitions.
Adapted to an everyday desktop workspace: warm off-white, forest green actions,
soft sage status surfaces, and a local system font stack for offline operation.

- Three steps: choose folder, set sequence, preview and rename.
- Settings sit beside a wide original/new filename table.
- Default prefix: `2026 06 22 FRA EMITIDA`; default starting number: `00140`.
- An optional Skip numbers field beneath the start number accepts comma-separated values and inclusive ranges, with inline validation and persistent settings. Preview and first-filename examples reflect the exclusions.
- Native folder picker; explicit preview before writing; no overwriting.
- Keep readable labels, keyboard focus, inline validation, accessible status messages.
- Paginate previews at 50 rows; support narrow windows and reduced motion.
- Text: #252f2a; secondary: #69716b; action: #355e43; background: #f6f7f4.
